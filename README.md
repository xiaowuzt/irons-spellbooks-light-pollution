# 铁魔法：光污染 / Iron's Spells: Light Pollution

Iron's Spells: Light Pollution is an Iron's Spells 'n Spellbooks addon for Minecraft 1.20.1 and Forge 47+. It adds 29 legendary-scale spells with animated astronomical scenes and dynamic coloured spell lighting.

## Requirements

- Minecraft 1.20.1
- Forge 47 or newer
- Iron's Spells 'n Spellbooks 1.20.1-3.16.1 or newer
- Iron's Lib 1.20.1-1.1.0 or newer

Event Horizon is an independent tilted, white-hot black hole with bent light arcs, HDR bloom, enemy attraction and a final collapse. It does not replace Gargantua. See `EVENT_HORIZON.md` for preview commands, defaults, verification and the upstream permission caveat.

Redshift Abyss is a separate volumetric accretion spell with a blue-white approaching side, orange-red receding side, orbital drag and final collapse. It preserves Event Horizon. See `REDSHIFT_ABYSS.md` for commands, appearance/gameplay controls and source attribution.

The black-hole family shares server-synchronized anchors and bh* parameters: Redshift Abyss supplies the volumetric disk, Schwarzschild Lens supplies the LUT-based lens, Radiant Collapse an inward damage shell, and Stasis Singularity local slow/pull/whitelisted absorption. Photon Corridor has been removed. They use mod-owned GLSL and colour/depth snapshots, not an Iris/OptiFine shader pack. The separate client file irons_spellbooks_light_pollution-black-holes.toml controls high/low/particle rendering. R3 is unavailable; no replacement was fabricated. Source permissions for R1/R4/R5 remain unverified; see THIRD_PARTY_NOTICES.md before redistribution.

## Configuration / 自定义配置

The server configuration is generated by Forge from the actual configuration specs. Each
registered spell exposes only the fields it consumes; optical-only spells do not receive
misleading damage controls. The key locations and examples are described below.

Gameplay is server-authoritative. Edit the world's file, not a similarly named client file:

`<world>/serverconfig/irons_spellbooks_light_pollution-server.toml`

For single-player this is `saves/<world>/serverconfig/`. To seed newly created worlds, put
server defaults in `defaultconfigs/`; existing worlds keep their own values. Restart/reload
as described in the guide, and recast a spell to apply values snapshotted at entity creation.
Damage/healing fractions are decimals (`0.08` means 8%); 20 ticks are one game-time second.

Client appearance/lighting lives in `config/irons_spellbooks_light_pollution-client.toml`;
shared black-hole rendering controls live in `config/irons_spellbooks_light_pollution-black-holes.toml`.
Client visual scale/brightness never changes server hit ranges or damage. The guide also
covers common safety settings and the separate dynamic-text client settings.

`commentLanguage = "AUTO"` in the common configuration follows the selected Minecraft
language on clients (`zh_*`/`lzh`: Chinese, otherwise English). Dedicated servers use
bilingual comments. `EN_US`, `ZH_CN` and `BILINGUAL` are explicit alternatives.
Changing comment language preserves existing values and inline comments; unsafe/malformed
or concurrently edited files are skipped rather than overwritten.

配置说明与示例包含所有已注册法术的配置入口、实际可用字段、默认值和范围。
服务端玩法与本机视觉配置分开；不要用客户端的大小/亮度选项修改伤害。
原有自定义值不会因切换注释语言而重置。旧开发版的 `spells.spells` 嵌套路径
仍需按中文教程迁移到对应的 `spells.<camelCaseId>`，不要整份覆盖自己的配置。

## Building

Use the Gradle wrapper from a Java 17 environment:

```text
./gradlew build
```

The resulting jar is written to `build/libs/`.
